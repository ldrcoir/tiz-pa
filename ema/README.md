# ema — مالِ ما

هرچه برای مسابقه ساخته می‌شود اینجاست:

- **[tizpa/](tizpa/)** — بازی اصلی تیزپا (پروژه گودوت ۴). اجرا: `godot --path ema/tizpa`
- **[tasavir/](tasavir/)** — عکس‌های مستندات بازی (منو، مسابقه، پلاک، میلاد، اینترو)
- **[abzarha/](abzarha/)** — اسکریپت‌های ساخت: مدل ماشین بلندری، پلاک تهران، سازندهٔ آهنگ

## وضعیت

- نسخهٔ ۰.۱ روی گوشی اجرا می‌شود (APK نصب‌شده و تست‌شده)
- ماشین جدید بلندری + پلاک + برج میلاد: ✅ انجام و تأییدشده روی گوشی
- UI رسپانسیو: هنوز انجام نشده — اولین کار نسخهٔ ۲
