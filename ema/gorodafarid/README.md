# گردآفرید — پلتفرمر نبردِ شاهنامه‌ای

هلیا در نقشِ **گردآفرید**، دلاورِ دژِ سپید: با **شمشیر** و **کمان** می‌جنگد، بر **اسبِ سپید** می‌تازد،
از سربازانِ توران و دیوان می‌گذرد و سرانجام **دیوسپید**، گردِ دژِ سپید را نابود می‌کند.

## اجرا
```
godot --path ema/gorodafarid
```
### کنترل
| کار | کیبورد | لمس (گوشی) |
| --- | --- | --- |
| حرکت | ← → یا A/D | دکمه‌های چپ/راست |
| پرش (دوبار = پرشِ دوم) | فاصله/↑/W | دکمهٔ بالا |
| شمشیر | X یا J | دکمهٔ شمشیر |
| کمان (خودنشانه‌رو) | C یا K | دکمهٔ کمان |
| سوارشدن اسب | E | دکمهٔ اسب |
| از نو | R | — |

## ویژگی‌ها
- **هنر ساخته‌شده با هوش مصنوعی**: ۱۶ قطعه به سبک نگارگریِ شاهنامه (هلیا-گردآفرید با روسری سرمه‌ای و
  جامهٔ قرمز، سرباز توران، دیو، دیوک، دیوسپید، اسبِ سپید، سوار، آسمان، کوه و دژ، شهر، کاشی، انار، سرو، دروازه)
  — جداسازی پس‌زمینه با کلیدِ کرومای هوشمند در `to/abzarha_gorodafarid/pardazesh_honar.py`
- **صدا و موسیقیِ ساختِ کد**: حلقهٔ همایون با سنتورِ پلاکِ کارپلس-استرانگ + ۱۲ جلوهٔ نبرد (`to/abzarha_gorodafarid/sakht_seda.py`)
- گیم‌پلی: کوایوت‌تایم، بافر پرش، پرشِ دوم، اسکواش/استرچ، لرزش و ضربه‌ایست، پارالاکس سه‌لایه،
  انارِ جان، چک‌پوینتِ پرچمِ سه‌رنگ، لگدِ اسب، نبردهای سرباز/دیو/دیوک و دوئلِ نهایی با دیوسپید
- **کنترل لمسی** برای موبایل (فقط روی صفحهٔ لمسی پیدا می‌شود) و چیدمانِ رسپانسیو (`stretch/aspect=expand`)
- خلبانِ خودکار برای دمو: `--aks` (اسکرین‌شات) و `--film` (فیلم‌برداری با `--write-movie`)

## ساختار
```
scenes/bazi.tscn      صحنهٔ اصلی
scripts/bazi.gd       رهبرِ صحنه: جهان، دشمنان، HUD، خلبانِ خودکار
scripts/helia.gd      هلیا-گردآفرید: حرکت، نبرد، اسب
scripts/doshman.gd    چهارنوع دشمن
assets/honar/         هنرهای پردازش‌شده + دکمه‌های لمسی
assets/audio/         موسیقی و جلوه‌ها (wav)
abzarha/              ابزارهای ساخت هنر و صدا
aks/                  اسکرین‌شات‌های زندهٔ نبرد
```
