- **[noor2d/](noor2d/)** — سه‌گانهٔ نور: «مدار»، «شب‌تاب»، «بادبادک تهران» (+ کتابچهٔ PDF)
- **[tasavir/](tasavir/)** — عکس‌های آزمایش‌ها
- **[abzarha/](abzarha/)** — اسکریپت‌های آزمایش (AI تصویربه‌سه‌بعدی، پردازش هنر)
