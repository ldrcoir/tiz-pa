# to/ezhdeha — اژدهای کوچولو 🐉

جوابِ «اژدها کوچولو بامزه شده ولی کاستوم‌هاش باید بیشتر می‌شد»:
**۹ کاستوم × ۴ حرکت = ۳۶ انیمیشن** — همه از پایپ‌لاینِ «عکسِ AI ← ورقِ فریم ← انیمیشنِ بازی».

## کاستوم‌ها
عادی، جادوگر، پلیس، فضانورد، دزد دریایی، شاه، زمستانی، مسابقه‌ای، نینجا

## حرکت‌ها (هر کاستوم، یک ورقِ ۱۱ فریمه)
| حرکت | فریم‌ها | سرعت |
|---|---|---|
| ist (ایستادن با نفس) | ۰–۱ | ۶fps |
| doid (دویدن با گردوخاک) | ۲–۵ | ۱۲fps |
| parsh (پرش: خم/پرتاب/فرود) | ۶–۸ | ۸fps |
| dam (پُفِ آتشِ دهان) | ۹–۱۰ | ۶fps |

## چیزهای داخلِ پوشه
- `kham/` — ۹ عکسِ خامِ AI (پس‌زمینهٔ سبزِ یکدست برای کلیدِ رنگی)
- `assets/honar/ezhdeha_<kastum>.png` — ورقِ فریمِ ۱۱ فریمهٔ هر کاستوم (۲۵۶×۲۵۶ در فریم)
- `kargah_data/` — ورق‌های webp + `ezhdeha.json` (برای کارگاهِ تحتِ وب)
- `ezhdeha.gd` / `main.gd` — صحنهٔ گودوت: دویدن + تعویضِ خودکارِ کاستوم + پرش + پُفِ آتش + پرشِ جشن
- `qc_vorudi.jpg` / `qc_pardazesh.jpg` — بازرسیِ قبل و بعد از کلیدِ رنگی
- `pishnamayesh.gif` — چرخهٔ دویدنِ اژدهای عادی

## اجرا
```
godot --path to/ezhdeha                          # خلبانِ خودکار، خروج در ۱۶.۶ ثانیه
godot --path to/ezhdeha -- --aks                 # یک عکس برای بررسی
godot --path to/ezhdeha --write-movie /tmp/f.avi --fixed-fps 30   # ضبطِ فیلم
```

```
python3 scripts/keshidan_ezhdeha.sh        # کشیدنِ ۹ عکس با AI
```
